# College Projects

This repository contains a collection of my college projects developed using different technologies and programming languages.

## Projects

### 1. AI Project
An AI-based project demonstrating concepts related to artificial intelligence and machine learning.

### 2. Age Calculator
An Android application that calculates a person's age based on their date of birth. The project also includes a backend for storing calculations.

### 3. IRA Project
A full-stack project that includes a machine learning component for student risk analysis, along with a web-based frontend and backend.

### 4. Trello MERN
A Trello-style task management application built using the MERN stack (MongoDB, Express.js, React, and Node.js).
